Built for everyone in the delivery chain.

Every order moves through the same real-time thread — the customer, the rider on the road, and the admin at the station all see it update instantly.

Customer

Order water, track it live, and never explain your address twice.

  • Order in a few taps — round, slim, or box gallons
  • Pin the exact delivery spot with GPS, or reuse a saved address
  • Pay with GCash, card, or cash on delivery
  • Watch the order move: accepted, picked up, on the way, delivered
  • Add a house photo so the rider finds the door faster
  • Rate the delivery — repeat orders auto-rebook the same rider

Rider

One map, one queue, zero guesswork on where to go next.

  • See every assigned delivery pinned on a live map
  • Check off gallons on a loading checklist before each trip
  • Get turn-by-turn navigation to each stop
  • Capture photo proof once a gallon is handed over
  • Go online/offline anytime, and pick up where signal drops
  • Track daily deliveries and earnings in one tab

Admin

The whole station — stock, riders, and revenue — in one dashboard.

  • Accept, reject, or bulk-assign incoming orders to a rider

  • Monitor tank stock and log every refill
  • Update prices and delivery fees, synced instantly to customers
  • Export a rider's daily orders and revenue as CSV

Security, by design

Every account and every order is protected.

The app runs on Supabase, with access rules enforced at the database level — not just inside the app itself.

Authenticated accounts

Every customer, rider, and admin signs in through Supabase Auth. Passwords are hashed and never stored in plain text, with each session running on a secure token.

Row Level Security

Database policies decide what each role can see — a customer only reads their own orders, a rider only their assigned deliveries — scoped at the source, not just hidden in the UI.

Email OTP verification

Registration, rider onboarding, and password resets all require a one-time code sent to the account's email before access is granted.

Protected file storage

House photos, delivery proofs, and rider ID uploads live in access-controlled storage buckets — not public folders anyone can browse.

Full audit trail

Every admin action — accepting an order, editing prices, assigning a rider — is logged with who did it and when, for full accountability.

Encrypted in transit

All traffic between the app and the server runs over HTTPS, so data can't be read or altered while it's moving.
